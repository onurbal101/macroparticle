# Research decisions

The default view uses tasks. Food results retain the parent function and full code. The user can also learn every physical control from a panel that follows TR09 p. 11. Its knob and separate Select/Clock key are distinct targets.

Auto Cook uses one countdown per code, based on readings the user supplied on 2026-11-19. Auto Cook quantities are fixed by code. Healthy Steam exposes only listed quantities. Defrost shows the documented range. The simulator uses the reported 100 g poultry increment as its default step. Automatic presets without recorded times display `AUTO`.

Instruction actions are data. Shared sequences cite their own procedure pages. Each food cites its table page. Safety guidance is attached to the relevant food or workflow. Personal bookmarks and notes are local app data. Appliance Favorite memories have their own guide.

All English food and instruction text is labeled as an application translation of TR09. Hardware English names remain the names printed in the control diagram. This avoids importing a different regional menu.

The user selected local implementation first and future hosting at https://macroparticle.onurbal.com. Print QR codes use this configurable production destination. They can be decoded now. Remote HTTP availability can be checked after deployment.

The app stores data on the device without an account or telemetry. Preferences are read defensively. All required instructions and source metadata are included in the app bundle and offline cache. Original Samsung PDFs open online. Printed cards use the same canonical records.

The print card uses two A5 landscape pages. Print double-sided and use the printer's short-edge option for a landscape flip. Check the printer preview. The full index uses A4 landscape pages with readable rows. Printed materials belong in a separate stand or safe nearby place with vents, door and controls clear.
