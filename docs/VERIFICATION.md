# Verification

Verify a release with `npm test`, `npm run validate`, `npm run build` and `npm run test:e2e`. The browser suite checks direct links, responsive layouts, offline use, and selected accessibility rules. Review the screenshot differences when the design changes.

The print generator decodes the QR images and checks their destinations. Confirm the destination URLs over HTTPS after deployment. Device installation and physical paper scans need a phone check.
